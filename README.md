# 会员经营看板

WPS 多维表格「社群管理系统」配套的网页看板工具。**只读源表**（会员客户台账），不依赖任何统计表、合并表。

👉 在线地址：https://shuaishuai03.github.io/wps-member-dashboard/

## 怎么用

1. 打开任意一个战区管理系统的多维表格 → 右上「更多 → 脚本 → AirScript 脚本」
2. 新建脚本，把 [`airscript/会员台账汇总.js`](airscript/会员台账汇总.js) 全文粘进去并运行
   （也可以直接在看板里点左侧「查看 AirScript 脚本」一键复制）
3. 复制控制台打印出来的那一整段 JSON
4. 打开看板 → 左侧「导入 AirScript 数据」→ 粘贴 → 导入

数据保存在浏览器本地（localStorage），刷新不丢；点「清空数据」可清除。**不会上传到任何服务器。**

## 指标口径（重要）

所有比率都由 **「先求和、再相除」** 计算：

| 指标 | 口径 |
|---|---|
| 对接率 / 观课率 | 已对接（已观课）客户数 ÷ 客户总数 |
| 成交率 | 成交客户数 ÷ 客户总数 |
| 观课→成交 | 成交客户数 ÷ 已观课客户数 |
| 二轮复购率 | 二轮成交客户 ÷ 首轮成交客户 |
| 三轮复购率 | 三轮成交客户 ÷ 二轮成交客户 |
| 客单价 | 成交金额合计 ÷ 成交客户数 |
| 获客成本 | 广告费合计 ÷ 客户总数 |
| 成交获客成本 | 广告费合计 ÷ 成交客户数 |
| 投产比 | 成交金额合计 ÷ 广告费合计 |

成交金额优先取「总金额」字段；该字段**为空或为 0** 时回退为 首轮 + 二轮 + 三轮 + 往期 金额之和。
两条路径互斥（填了总金额就完全信它，没填才用分轮兜底），既不会重复计算、也不会漏算。
若某些行只填了总金额、没拆分到各轮，「成交金额构成」环形图下方会说明这部分金额有多少。

### 投入类指标的警示逻辑（新增）

广告费在实际填报中经常**只有部分战区/部分行填了**。此时
「全部战区的成交额 ÷ 部分战区的广告费」会让投产比虚高、成本虚低，是典型的静默错误。看板的处理：

| 情况 | 表现 |
|---|---|
| 参与计算的行里只有一部分填了广告费 | 视图顶部出现**橙色警示条**，写明「仅 X/Y 个战区填报了广告费，仅 M/N 行有广告费」，并列出未填报的战区；同时在**投产比**、**广告费/获客成本** KPI 卡的副标题和**成交获客成本**指标格上打 ⚠ 标记 |
| 参与计算的行**全部**没填广告费 | 投产比 / 广告费 / 获客成本 / 成交获客成本一律显示 `—`（**不是 0**），并给出「投入类指标不可用」提示条 |
| 组织效能明细表 | 未填广告费的单位，其「投产(x)」列显示 `—` 而不是 0；表格下方注明该列只对已填报单位有效 |

### 其它数据健壮性口径

| 情况 | 处理 |
|---|---|
| 金额被存成字符串（`"0"` / `""` / `"1,200"` / `¥800`） | 求和时按数值解析，空值按 0 |
| 空串 / `null` 与 0 的区别 | `""`/`null` 视为「没填」，**不参与比率的分母**（如投产比的广告费）；求和时按 0 |
| 日期三种形态 | ISO 串、`2026/8/31 17:26` 文本、Excel 序列号（数字或字符串，如 `46265.72`）统一还原为本地日期，序列号按整数天换算以避免时区跨天 |
| 是否类字段 | `是 / 否 / 已成交 / 已对接 / 已观课 / true / 1 / "1" / ✓ / √ / ☑ / 空` 等写法全部正确判定；`"0"` / `否` / `未成交` 判为否 |
| 大量空行（只有创建时间） | 自动识别并**排除在所有指标之外**，但仍完整出现在「客户明细」里；筛选栏与明细页注明有多少空行 |
| 占比类图表的「未填写」 | 环形图默认过滤掉「未填写」，并在图下注明过滤了多少行，避免它挤成一大块 |
| 多战区混合 | 出现 2 个及以上战区时自动显示「战区」筛选；「轮次走势」按战区拆成多条线，并提示各战区轮次编号口径不同、建议先筛选单个战区 |
| 导入失败 | 报出具体原因：缺第几段、JSON 在第几个字符/第几段处断开并给出断点上下文，而不是笼统的「解析失败」 |
| 导入成功 | 左上角显示战区名与记录数（含空行数量），弹窗提示参与指标的行数 |

## 脚本特性

- **按字段名读取**：源表调整字段顺序、插入新列都不影响结果
- **只读**：不创建表、不写入、不修改任何记录
- 自动识别表名中的「会员客户台账」关键字，跳过 📊 统计表
- 兼容人员/关联/选项等对象型字段，日期兼容 ISO 串、`yyyy/MM/dd` 文本与 Excel 序列号

## 跨战区汇总

在每个战区分别运行脚本，把多份 JSON 的 `detail` 数组合并成一份再导入，看板顶部会自动出现「战区」筛选。

## 技术说明

单文件 HTML，零依赖（图表全部为手写 SVG），支持浅色/深色主题自动跟随系统。配色经过色盲可辨性（CVD ΔE）与对比度校验。
