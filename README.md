# 会员经营看板

WPS 多维表格「社群管理系统」配套的网页看板工具。**只读源表**（会员客户台账），不依赖任何统计表、合并表。

👉 在线地址：https://shuaishuai03.github.io/wps-member-dashboard/

## 怎么用

1. 打开任意一个战区管理系统的多维表格 → 右上「更多 → 脚本 → AirScript 脚本」
2. 新建脚本，把 [`airscript/会员台账汇总.js`](airscript/会员台账汇总.js) 全文粘进去并运行
   （也可以直接在看板里点左侧「查看 AirScript 脚本」一键复制）
3. 复制控制台打印出来的那一整段 JSON
4. 打开看板 → 左侧「导入 AirScript 数据」→ 粘贴 → 导入

数据保存在浏览器本地（localStorage），刷新不丢；点「清空数据」可清除。**不会上传到任何服务器。**

## 五个视图

| 视图 | 内容 |
|---|---|

| 客户结构 | 客户分类/引流渠道/地址区域/客户状态四张分布图、渠道质量对比、客户分类成交率排行、地区×轮次成交金额热力图 |

## 指标口径（重要）

所有比率都由 **「先求和、再相除」** 计算：

| 指标 | 口径 |
|---|---|
| 对接率 / 观课率 | 已对接（已观课）客户数 ÷ 客户总数 |
| 成交率 | 成交客户数 ÷ 客户总数 |
| 观课→成交 | 成交客户数 ÷ 已观课客户数 |
| 二轮复购率 | 二轮成交客户 ÷ 首轮成交客户 |
| 三轮复购率 | 三轮成交客户 ÷ 二轮成交客户 |
| 客单价 | 成交金额合计 ÷ 成交客户数 |
| 获客成本 | 广告费合计 ÷ 客户总数 |
| 成交获客成本 | 广告费合计 ÷ 成交客户数 |
| 投产比 | 成交金额合计 ÷ 广告费合计 |

成交金额优先取「总金额」字段；该字段为空时回退为 首轮 + 二轮 + 三轮 + 往期 金额之和。
「是否成交/是否对接/是否观课」兼容 `是 / 已成交 / true / 1 / ✓` 等多种写法。

## 脚本特性

- **按字段名读取**：源表调整字段顺序、插入新列都不影响结果
- **只读**：不创建表、不写入、不修改任何记录
- 自动识别表名中的「会员客户台账」关键字，跳过 📊 统计表
- 兼容人员/关联/选项等对象型字段，日期兼容 ISO 串、`yyyy/MM/dd` 文本与 Excel 序列号

## 跨战区汇总

在每个战区分别运行脚本，把多份 JSON 的 `detail` 数组合并成一份再导入，看板顶部会自动出现「战区」筛选。

## 技术说明

单文件 HTML，零依赖（图表全部为手写 SVG），支持浅色/深色主题自动跟随系统。配色经过色盲可辨性（CVD ΔE）与对比度校验。
